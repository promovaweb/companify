# Glossário: termo interno → linguagem simples

Use a coluna da direita ao falar com o usuário. A coluna da esquerda é o
termo técnico que as demais skills `companify-*` esperam e registram nos
arquivos; não precisa aparecer na conversa, a menos que o usuário pergunte
"onde isso fica salvo" ou peça o termo técnico.

| Termo interno | Como dizer para o usuário |
| --- | --- |
| Company Context | O resumo da sua empresa que a gente vai construindo junto. |
| `.companify/`, `company/` | Os arquivos onde tudo o que a gente decide fica guardado. |
| Estágio (`idea`, `validation`, `pre-revenue`...) | Qual fase você está vivendo: só ideia, já testando, já vendendo... |
| Gate (Context, Viability, Executive Alignment, Business Plan) | Uma checagem rápida antes de avançar, pra garantir que nada importante ficou pra trás. |
| `companify-interview` | A conversa inicial pra te conhecer melhor. |
| `companify-market` | A parte de entender quem compra e quem já disputa esse mercado com você. |
| `companify-business-model` | Como o dinheiro entra: o que você vende e como cobra. |
| CEO (`companify-ceo`) | A visão geral: por que essa empresa existe e pra onde ela vai. |
| CPO (`companify-cpo`) | O produto ou serviço em si: o que você entrega de verdade. |
| CTO (`companify-cto`) | A parte técnica: o que construir, o que comprar pronto. |
| CMO (`companify-cmo`) | Como as pessoas vão descobrir e confiar na sua empresa. |
| CRO (`companify-cro`) | Como fechar vendas e cobrar por isso de forma sustentável. |
| CFO (`companify-cfo`) | As contas: quanto entra, quanto sai, quanto sobra. |
| COO (`companify-coo`) | Como o dia a dia funciona pra entregar o que foi vendido. |
| CHRO (`companify-chro`) | Quem você precisa ter no time, e em qual ordem contratar. |
| `companify-ameacas` | O que pode dar errado, e o que fazer se acontecer. |
| `companify-board` | Um momento de confrontar as respostas de cada área quando elas se contradizem. |
| Escolha registrada (`ESC-NNN`) | Uma escolha que a gente já bateu o martelo, com o motivo escrito. |
| Comprovação | Uma prova real por trás de uma afirmação (não é só achismo). |
| Premissa | Um número que a gente está assumindo porque ainda não dá pra confirmar. |
| `companify-business-plan` | A versão final juntando tudo num só documento. |
| `companify-audit` | Uma revisão final pra ver se ficou tudo consistente. |
| Plano de 90 dias | O que fazer nos próximos três meses, sem enrolação. |

## Frases prontas para abrir cada etapa

Use como inspiração, adapte ao que a pessoa já disse:

- "Antes de mais nada, me conta em uma frase: o que sua empresa faz ou vai fazer?"
- "Agora vamos entender quem compra isso e quem mais está tentando vender pra esse mesmo público."
- "Como você pretende ganhar dinheiro com isso? Não precisa ter certeza, um chute educado já serve pra começar."
- "Vou te fazer algumas perguntas rápidas de quem entende de vendas, só pra afinar o preço e o jeito de vender."
- "Chegou a hora das contas: não se preocupe se não souber os números exatos, a gente trabalha com faixas."
- "Deixa eu juntar tudo isso num plano só, pra você ver o quadro completo."
